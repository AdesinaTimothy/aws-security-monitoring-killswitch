CloudWatch Logs metric filter pattern (Flow 1)
----------------------------------------------
Log group: security-monitoring-trail-cwlogs
Namespace: SecurityMetrics
Metric name: SecretAccessCount
Metric value: 1
Default value: 0   (emits 0 when no match, so the alarm always has data)

Filter pattern:

{ ($.eventName = "GetSecretValue") && ($.requestParameters.secretId = "*Production_Database_Credentials*") }

Notes:
- The wildcards around the secret name matter: CloudTrail often records
  secretId as the full ARN (with a random suffix), not the plain name.
- No dimensions are used, so the default-value-0 mechanism works and the
  alarm can rest cleanly in the OK state.
